# 📸 Manual Image Organization Guide

## Folder Structure

All images should be placed in:
```
images/injection_points/{region_folder}/
```

---

## File Naming Convention

**Format:** `{region}__{injury}__{number}.png`

- **Region**: Lowercase, spaces/hyphens → underscores
- **Injury**: Lowercase, spaces/hyphens → underscores  
- **Number**: 01, 02, 03, etc. (zero-padded)

**Example:**
```
right_knee_medial__mcl_sprain__01.png
right_knee_medial__mcl_sprain__02.png
left_shoulder__rotator_cuff_tear__01.png
```

## Summary

- **Total Regions:** 68
- **Total Unique Images Needed:** ~350+ (you can have multiple images per injury)
- **Format:** PNG files
- **Naming:** Lowercase with double underscores as separators
- **Add numbers** (01, 02, 03) if you have multiple images for the same injury

---

## Tips

1. **You don't need all images** - Start with the most common injuries
2. **Multiple images per injury** - Use __01, __02, __03 suffixes
3. **Reuse images** - Same image can be used for similar injuries
4. **Test as you go** - Add a few, test in app, then continue

---

## How Images Display in App

When you hover over a green injection sphere:
- Up to 3 thumbnails shown in tooltip
- Click thumbnail to view full-size
- Images loaded from folder structure automatically

The app will automatically detect and display any PNG images you add following this naming convention!
