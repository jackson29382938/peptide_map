# Injection Point Images

Place your PNG images in subfolders matching the region names.

## Folder Structure

Create subfolders for each body region:
- head/
- neck/
- right_knee_medial/
- left_shoulder/
- etc.

## File Naming

Format: `{region}__{injury}__{number}.png`

Example:
```
right_knee_medial/right_knee_medial__mcl_sprain__01.png
```

## Quick Start

1. Create folder for your region
2. Add PNG file with correct naming
3. Update js/injection-images.js
4. Test in browser
